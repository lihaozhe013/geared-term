# Geared Term

Geared Term is a cross-platform desktop terminal built with Electron, TypeScript, React, and xterm.js. It brings local shells, WSL, SSH connections, file operations, and an AI assistant into one workspace.

## Features

- Local terminal sessions, WSL distributions, and SSH connections
- Multiple terminal tabs and saved session profiles
- Local file browsing and SFTP file transfer for SSH sessions
- Remote file editing and configurable terminal themes
- API-based AI assistant with conversation history
- Encrypted storage for credentials and other sensitive settings
- Packaging support for Windows, macOS, and Linux
